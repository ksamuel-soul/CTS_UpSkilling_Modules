Welcome to the CTS Upskilling program! This repository contains comprehensive learning materials organized into three main modules covering web development fundamentals, database management, and backend development.

---

## 📚 Module Overview

### Module 1: Frontend Web Development
Complete training in modern web development from basics to advanced frameworks.

#### Topics Covered:
1. **HTML (10 Exercises)**
   - HTML5 base template creation
   - Navigation and linking
   - Forms and form handling
   - Media elements (video/audio)
   - Web APIs (Geolocation, Storage)
   - Debugging with Chrome DevTools

2. **CSS (10 Exercises)**
   - CSS syntax and styling methods (inline, internal, external)
   - Selectors and specificity
   - Colors and backgrounds
   - Typography and fonts
   - Box model and layout
   - Responsive design with media queries
   - Development tools and debugging

3. **Bootstrap (19 Exercises)**
   - Bootstrap 5 setup and structure
   - Responsive grid layout system
   - Column layouts and alignment
   - Flexbox utilities
   - Typography and forms
   - Buttons and navigation
   - Cards and media objects
   - Spacing utilities
   - Colors and backgrounds
   - Display and visibility
   - Borders, shadows, and styling
   - Bootstrap Icons integration
   - JavaScript plugins
   - Sass customization

4. **JavaScript (14 Exercises)**
   - JavaScript basics and setup
   - Syntax, data types, and operators
   - Conditionals, loops, and error handling
   - Functions, scope, and closures
   - Objects and prototypes
   - Arrays and array methods
   - DOM manipulation
   - Event handling
   - Async JavaScript, Promises, and Async/Await
   - Modern JavaScript features (ES6+)
   - Working with forms
   - AJAX & Fetch API
   - Debugging and testing
   - jQuery and JS frameworks

5. **jQuery (6 Exercises)**
   - jQuery library inclusion
   - The $() function and selectors
   - jQuery methods
   - DOM manipulation with jQuery
   - Event handling with jQuery
   - Event helpers

Backend programming and application development.

  - Object-oriented programming
  - ASP.NET basics
  - Backend application development
  - Database integration

## 🎯 Learning Path

**Recommended Order:**
1. Start with **HTML** (fundamental markup)
2. Move to **CSS** (styling and layout)
3. Learn **Bootstrap** (responsive frameworks)
4. Study **JavaScript** (interactivity and logic)
5. Practice **jQuery** (DOM manipulation)
6. Advance to **MySQL** (database concepts)
7. Complete with **C#** (backend development)
